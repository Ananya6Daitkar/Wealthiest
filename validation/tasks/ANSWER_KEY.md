# Facilitator/adjudicator only

Have a non-developer check this policy before testing. Both sets start at INR 400,000 for EVERY case.

| Case | Expected supported outcome | Set A final principal | Set B final principal |
|---|---|---:|---:|
| new | Add different, fully identified deposit | 580000 | 620000 |
| duplicate | Use the reference card to attribute FD-1007, attach evidence without adding principal | 400000 | 400000 |
| conflict | Flag conflicting principal; absent verification, leave unresolved and do not change principal | 400000 | 400000 |
| unresolved | Do not infer principal from maturity; leave unresolved | 400000 | 400000 |

Score both decision and final total, not the total alone. Arbitrarily selecting a conflicting source is unsupported even if the UI permits human selection. Record blocked/incorrect/abandoned outcomes separately. The cards are deliberately small and similar; task familiarity and developer authorship limit generalization.
