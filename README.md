# NestProof

**Resolve ambiguous financial imports with the least user effort.**

NestProof is a proposed WealthNest.AI Track C project. It combines document interpretation, evidence checks, targeted clarification, historical context and reversible correction previews to help users review financial records before changing represented family wealth.

## Research and design

- [Research and design — Parts A–M](docs/RESEARCH_AND_DESIGN.md): product investigation, research papers, competitors, ten ranked ideas, selected solution, architecture, evaluation and development plan.
- [Concise case study](docs/CASE_STUDY.md): problem, investigation, proposed workflow, current evidence and next steps.

The research incorporates approaches from FINBOURNE, Canoe Intelligence, Addepar and Singapore's SGFinDex, with source links and explicit distinctions between documented capabilities and our proposed adaptations.

## Current status

This initial repository commit contains documentation only. The full application is not built. Research proposes an FD-first prototype using synthetic data, local model inference and a user-confirmed correction workflow.

The documents report a locally executed synthetic text-only rules baseline. Its scripts and generated fixtures are not included in this initial documentation commit. No measured AI improvement or real-user benefit is claimed.

The original 85/100 assessment is a provisional design judgment. The revised 99/100 rubric is an aspirational evidence checklist, not an achieved score, an official WealthNest rubric or a guarantee of hackathon success.

## Planned workflow

Authorized upload → typed extraction → source and identity/date checks → targeted clarification → supported correction preview → confirmation → commit and undo/history.

Next: validate the current product workflow, build the scoped prototype, compare against strong deterministic baselines and measure resolution quality and user effort.
